What happens next?

  1. The artifact is deserialized and smoke-checked — invalid files are rejected with a typed 422 and cleaned up.
  2. The model enters the catalog with a collision-safe ID and is served warm from the LRU cache.
  3. A default predict-scoped API key is minted automatically.
  4. Predict immediately via POST /api/predict/{model_id} — and watch it land on the dashboard in real time.
