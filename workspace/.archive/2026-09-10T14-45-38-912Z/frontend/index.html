How It Works

Three calls from notebook to production

01

Upload Your Model

Drop a trained .pkl artifact. It is deserialized, validated, task-detected and cached warm — a default API key is minted automatically.

POST /api/upload
  name: "spam-classifier"
  file: model.pkl
02

Scope Your Keys

Generate purpose-scoped keys — one for production, one for batch jobs, one read-only for analytics. Revoke instantly when a key leaks.

POST /api/keys
  → { "key": "mf_a1b2c3..." }
03

Predict & Watch Live

Send any input shape; get predictions with latency telemetry. The dashboard updates over WebSocket the same millisecond you get the response.

POST /api/predict/{model_id}
  X-API-Key: mf_a1b2c3...
  { "data": [...] }
  → { "prediction": ..., "latency_ms": 3.8 }
